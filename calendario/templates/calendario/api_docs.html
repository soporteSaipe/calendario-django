    Documentación de API

    Esta es la documentación completa de los endpoints disponibles en el sistema de calendario.

    GET
    Obtener Reservas
    /calendario/api/reservas/

    Descripción: Obtiene las reservas en formato JSON para el calendario.

    Parámetros:
    • start (opcional) - Fecha de inicio (formato ISO)
    • end (opcional) - Fecha de fin (formato ISO)
    • sala (opcional) - ID de la sala/recurso
    GET
    Validar Conflictos
    /calendario/api/validar-conflicto/

    Descripción: Valida conflictos de reservas en tiempo real antes de crearlas.

    Parámetros:
    • sala (requerido) - ID de la sala/recurso
    • fecha (requerido) - Fecha en formato YYYY-MM-DD
    • hora_inicio (requerido) - Hora de inicio en formato HH:MM
    • hora_fin (requerido) - Hora de fin en formato HH:MM
    GET
    Detalles de Sala
    /calendario/api/sala/<id>/detalles/

    Descripción: Obtiene información detallada de una sala específica.

    Parámetros:
    • id (requerido) - ID de la sala (en la URL)
    Respuesta incluye:
    • Nombre, capacidad y color de la sala
    • Descripción detallada
    • Características (proyector, pizarra, audio, etc.)
    • Horario de uso
    GET
    Horarios Ocupados
    /calendario/api/horarios-ocupados/

    Descripción: Obtiene los horarios ocupados de un recurso en una fecha específica.

    Parámetros:
    • recurso_id (requerido) - ID del recurso
    • fecha (requerido) - Fecha en formato YYYY-MM-DD
    Información
    • Todos los endpoints requieren autenticación
    • Las respuestas son en formato JSON
    • Se aplica rate limiting según el tipo de endpoint
    • Los errores incluyen códigos de error específicos
